Every left/right choice comes from `index` (not from the prover's `position` labels, which must agree), the branch must be exactly as deep as a tree of `leafCount` leaves, and a self-paired step is accepted only for the odd last node of a level. With `leafCount` pinned by a signed commitment, an inner node cannot pass as a leaf and a padded (CVE-2012-2459) tree cannot stand in for the real one.
