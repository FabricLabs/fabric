Class: DocumentBlobTransferBook

Edit this page

DocumentBlobTransferBook(optsopt)

Buyer-side reassembly of indexed blob transfers. Two tables: - **Expectations** (`expectTransfer`): what the buyer asked / paid for. Only the local caller writes them; unsolicited frames can never evict them. Each lives until `expiresAt` (caller-set, default an hour), is refreshed by matching frames (DocumentBlobTransferBook#touch), and ends with DocumentBlobTransferBook#releaseTransfer or completion. - **Assembly rows** (`ingest`): bytes received so far. Rows backed by an expectation are *pinned*; others are unsolicited and bounded by `maxPending` rows overall, `maxPendingPerOrigin` rows and `maxPendingBytesPerOrigin` bytes per sending peer, idle `ttlMs`, and are evicted (oldest first) before any pinned row. A row whose `total` contradicts the expectation (planted before the purchase) is replaced.

(static) verifySealedFrame(obj, expected) → {Object}

Verify-before-pay: check one free sealed per-blob `P2P_FILE_SEND` body (ciphertext of blob `i`) against the document root **before** funding the HTLC for `K_i`. The ciphertext must hash to its `blobHashHex` and the leaf `(blobHash, paymentHash, iv)` must open to the root with the frame's inclusion proof (or `expected.proof`). Pins from verified offer leaves (Document.verifyOfferLeaves) are enforced when given.
