Module: types/witness/adaptor

BIP-340 Schnorr adaptor signatures. A pre-signature on `message` under `publicKey` for the adaptor point `T = t·G` is `R̂ ‖ s'` (65 bytes): the compressed final nonce `R̂ = k·G + T` and `s' = k + e·d`, where `k` is negated when `R̂` has an odd y so that the completed signature `(x(R̂), s' ± t)` is a valid BIP-340 signature. Anyone holding the pre-signature and the completed signature learns `t`. Adapting and extracting follow secp256k1-zkp `musig_adapt` / `musig_extract_adaptor` (t is negated when the final nonce has an odd y); module:types/witness/musig2Adaptor uses the same arithmetic for 64-byte MuSig2 pre-signatures plus their nonce parity.
