Class: Tree

Edit this page

Tree(settingsopt) → {Tree}

Class implementing a Bitcoin Merkle Tree in display (RPC) byte order: SHA256d parents over byte-reversed children, and an odd last node paired with itself. Txid leaves in block order give the block header's `merkle_root`; one leaf is its own root and no leaves give an empty root. Leaf encoding, proofs, and verification match `merkletreejs` `isBitcoinTree` (which this replaced), so earlier roots are unchanged. Optional `sortLeaves` makes the leaf order lexicographic so adjacent-leaf **non-inclusion** proofs are well-defined (inclusion proofs work either way). Like Bitcoin's, the root does not commit the leaf count: `[a, b, c]` and `[a, b, c, c]` share a root. Tree#mutated flags such leaf lists and `rejectMutated: true` refuses them; callers that accept leaves from the network must check one or the other and bind the count separately.
