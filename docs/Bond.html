Class: Bond

Bond()

new Bond()

Publisher bounty and provider deposit terms as Taproot outputs (Policy leaves) layered on Contract. **Bounty** (decision 1): one P2TR output per epoch. Leaves: for every eligible provider a hashlock `SHA256(R_{epoch,provider})` + `CHECKSIG provider` claim, and a publisher `CHECKSIG` refund after `refundAfter`. The publisher reveals `R_{epoch,provider}` only to a provider that passed that epoch's Challenge; the preimage is derived from a publisher seed so nothing per-epoch has to be stored. No custodian. **Deposit** (decision 2): one P2TR output per provider commitment round. Leaves: a 2-of-2 `{ publisher, provider }` penalty leaf, a 2-of-2 check-in leaf (CSV 1), a provider-only withdraw after `withdrawAfter`, and — when the round commits an answer hash — the provider-only **answer** leaf `OP_SHA256 OP_EQUALVERIFY OP_CHECKSIG`, opened by the possession digest `SHA256(nonce || blob)`. Rounds: the publisher plans round `n` (`Challenge.planRound`), builds deposit `D_n` with that answer hash, and issues challenge `n` naming `D_n`'s outpoint. The provider checks the answer hash against its blob and pre-signs the timelocked penalty `P_n` acknowledging the challenge (Bond.signPenaltyAsProvider). Only then does the publisher co-sign check-in `C_{n-1}` (`D_{n-1}` → `D_n`). If the publisher withholds the check-in, the provider answers on-chain through `D_n`'s answer leaf before the deadline, which consumes the outpoint `P_n` spends — so the publisher cannot manufacture a non-response. Funds move only through those pre-signed / co-signed paths: Bond.preparePenaltySpend builds an unsigned 2-of-2 spend that still needs the provider's signature (adjudicated or cooperative settlement), never a unilateral seizure. **Fidelity** (coinjoin market): A maker locks coins in a P2TR output that only its bond key can spend, and only after a block height (` OP_CHECKLOCKTIMEVERIFY OP_DROP OP_CHECKSIG` under the NUMS internal key, so there is no key path). Locked capital is costly to fake, so takers weight makers by bond value and a Sybil attacker must lock coins for every identity it runs. The bond key signs a certificate binding the bond to the maker's offer key until `certExpiresAt` (a block height), so the bond key itself can stay cold. Takers check the certificate, then the UTXO on chain: unspent, the expected script, confirmed. Value follows JoinMarket's formula (interest on the locked amount over the lock period, decaying once the lock has expired, raised to an exponent so splitting a bond across identities loses value). Mainnet locktimes sit on a 4320-block grid (about a month) so bonds are not fingerprinted by odd heights.

Check a check-in PSBT before co-signing or recording it: one input on `previous`'s output through its `checkin` leaf, one output paying `next.address` (which becomes `nextOutpoint` when given), fee within `maxFeeSats`.

next object deposit receiving the funds
