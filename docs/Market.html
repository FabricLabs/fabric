 60000 Verify-before-pay: wait this long for the seller's free ciphertext (and quote).
verifyBeforePay boolean <optional>
 true Pay a sealed blob only once its ciphertext is held and committed by the root.
quotes boolean <optional>
 false Ask sellers for a per-buyer `DocumentBlobQuote`. The HTLC still pays the committed content hash. A quote hash is `SHA256(s)` and the wrap cannot be checked until `s` is revealed, so paying it lets the seller claim without delivering the key.
credit boolean <optional>
 true Take a seller's credit offer (`creditRateSats`) when a channel with it can pay: the key comes first, and the blob is paid with a channel transfer only once it opens. A blob that does not open is never paid.
seed Object | boolean <optional>
 Seed after download: sell every received convergent document again as the same tree, on these `Peer#publishSealedDocument` terms (`{ rateSats, creditRateSats, creditLimitSats }`; `true` = free).
fundingSafetyMs number <optional>
 3600000 A funding whose outcome is unknown is released only after the address is reported unfunded this long after the last pay attempt.
minHtlcLockBlocks number <optional>
 24 Refuse L1 HTLCs whose refund locktime is closer than this to the tip (or past).
maxHtlcLockBlocks number <optional>
 4032 Refuse L1 HTLCs that lock funds longer than this (0 = no cap).
channelExpirySlackBlocks number <optional>
 6 Blocks added to the channel's minimum HTLC expiry delta (tip skew).

 Destination for buyer refunds (`(session) => address` allowed).
