(inner) verifyAggregate(signature, message, publicKeys) → {boolean}

Verify one aggregate signature against the sum of public keys (same message). Not safe against rogue-key attacks on its own: a signer who picks its public key as a function of the others can make the sum verify alone. Only pass public keys whose proofs of possession were checked (as verifyFederationBlsBundle does); federation witnesses use verifyFederationBlsWitness, which never sums keys.
