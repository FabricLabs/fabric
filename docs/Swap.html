(async) fund() → {Promise.<Object>}

L1 giver: fund the HTLC. A maker that asked for a prepay funds only once its node reports the prepay invoice paid. Funding happens at most once: the escrow is recorded before the send, and once the send returns the swap is `l1Funded` (refundable, no longer abortable) even if the funding notice cannot be built — that error is thrown after the transition.

(static) bitcoinAdapter(service, optionsopt) → {Object}

Bitcoin adapter over `services/bitcoin` (bitcoind JSON-RPC, wallet loaded). Reading the counterparty's funding transaction needs it in the mempool or `txindex=1`. `fundAddress` rejects only when `sendtoaddress` fails; once it returns a txid, a failed transaction lookup yields `{ txid, txHex: null }` and the swap reads the transaction by txid later. A timeout on `sendtoaddress` itself still leaves the outcome unknown.
