@fabric/core

Simple, robust demonstrations of identity, signed chat, and onion forward. Run locally with Node 24.15, or browse the literate sources on this Pages site.

Curated Node demos

  1. npm run example:basic — Key + Schnorr sign/verify chat message
  2. npm run example:demo — Collection + signed shoutbox line
  3. npm run example:chat — UTF-8 chat smoke (--interactive for REPL)
  4. npm run example:onion — Offline P2P_FORWARD peel round-trip
  5. npm run example:smoke — Run the curated set

Clone: FabricLabs/fabric · Shell: npm start
